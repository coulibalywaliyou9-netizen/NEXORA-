# NEXORA

**L'IA qui invente pour le monde depuis l'Afrique.**

---

## Vision

L'Afrique n'a pas besoin d'attendre que le monde invente pour elle.
Elle peut inventer pour le monde.

NEXORA est un systeme d'intelligence artificielle capable de raisonner comme un scientifique, de concevoir comme un ingenieur, et d'imaginer comme un visionnaire — dans les limites strictes de la physique et du possible.

---

## Architecture : 8 agents specialises

| Agent | Role |
|-------|------|
| Chercheur | Lit les publications scientifiques recentes (Crossref) |
| Physicien | Calcule la physique reelle (meteo live, temperature cellule, rendement) |
| Critique | Verifie la plausibilite des resultats |
| Analyste | Fait raisonner une IA (Groq) sur les donnees |
| Ingenieur | Concoit des solutions avec des materiaux locaux |
| Visionnaire | Imagine le futur |
| Memoire | Archive chaque analyse dans un historique date |
| Historien | Analyse les tendances dans le temps |

**+ un Orchestrateur** qui fait tourner tout le cycle avec une seule commande.
