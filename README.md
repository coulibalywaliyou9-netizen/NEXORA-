# NEXORA

**L'IA qui invente pour le monde depuis l'Afrique.**

---

## Vision

L'Afrique n'a pas besoin d'attendre que le monde invente pour elle.
Elle peut inventer pour le monde.

NEXORA est un système d'intelligence artificielle capable de raisonner comme un scientifique, de concevoir comme un ingénieur, et d'imaginer comme un visionnaire — dans les limites strictes de la physique et du possible.

---

## Architecture : 6 agents spécialisés

NEXORA n'est pas un seul programme. C'est une symphonie d'agents qui se coordonnent.

| Agent | Rôle |
|-------|------|
| 🔬 **Chercheur** | Lit les publications scientifiques récentes (Crossref) |
| ⚛️ **Physicien** | Calcule la physique réelle (météo live, température cellule, rendement) |
| ⚖️ **Critique** | Vérifie la plausibilité des résultats |
| 📚 **Analyste** | Fait raisonner une IA (Groq) sur les données |
| 🔧 **Ingénieur** | Conçoit des solutions avec des matériaux locaux |
| 🧠 **Mémoire** | Archive chaque analyse dans un historique daté |

**+ un Orchestrateur** qui fait tourner tout le cycle avec une seule commande.

---

## Ce que NEXORA fait concrètement

En une commande (`python orchestre.py`), le système :

1. Cherche dans la science mondiale les dernières découvertes
2. Récupère la météo réelle de Ouagadougou
3. Calcule la température de cellule et le rendement réel
4. Vérifie que tout est physiquement plausible
5. Fait analyser les résultats par une IA
6. Propose un design d'ingénierie chiffré en FCFA
7. Archive le rapport dans son historique

**Résultat : en 45 secondes, une invention locale basée sur la science mondiale.**

---

## Exemple d'invention générée

**Problème :** Les panneaux solaires au Sahel perdent ~10 % de rendement à cause de la chaleur.

**Solution proposée par NEXORA :**
- Bassin d'eau de 5 cm de profondeur sous chaque module
- Dissipateur en cuivre
- Revêtement polycarbonate
- **Coût : ~11 000 FCFA par module** (~20 USD)
- **Gain attendu : +5 % de rendement absolu, +150 kWh/an par module de 300 W**

Tous les matériaux sont disponibles localement au Burkina Faso.

## Fichiers du projet

- `orchestre.py` — Lance tout le cycle
- `chercheur.py` — Trouve les publications scientifiques (Crossref + IA)
- `rapport.py` — Calcule la physique solaire avec météo live
- `critique.py` — Vérifie la plausibilité
- `analyste.py` — Fait raisonner l'IA (Groq)
- `ingenieur.py` — Conçoit un design local
- `memoire.py` — Archive les résultats
- `soleil.py` — Calculateur solaire de base
- `meteo.py` — Récupération météo live

## Installation

Prérequis : Python 3.10+, une clé API Groq gratuite (console.groq.com)

    pip install requests

Crée un fichier `.groq_key` contenant ta clé API Groq.
