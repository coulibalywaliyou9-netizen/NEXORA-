# NEXORA

Projet NEXORA - IA qui invente pour le monde.

## Vision

L'Afrique n'a pas besoin d'attendre que le monde invente pour elle. Elle peut inventer pour le monde.

NEXORA est un projet d'intelligence artificielle capable de raisonner comme un scientifique, de concevoir comme un ingénieur, et d'imaginer comme un visionnaire — dans les limites strictes de la physique et du possible.

## Premier terrain d'exploration : le soleil du Sahel

- **soleil.py** : calculateur photovoltaïque basé sur les lois physiques (température de cellule, perte de rendement, gain de refroidissement).
- **meteo.py** : récupère les données météo réelles de Ouagadougou via l'API Open-Meteo et calcule la température de cellule et le rendement en temps réel.

## Exemple de résultat

    Air: 34.2 C
    Cellule: 58.2 C | Rendement: 86.7 %

## Prérequis

- Python 3.10+
- requests

## Installation

    pip install requests

## Exécution

    python meteo.py
